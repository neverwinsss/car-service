# АвтоПрофи — сайт автосервиса (ASP.NET Core MVC + SQLite)

Учебный проект по ТЗ «Автосервис»: публичный сайт, онлайн-запись с выбором даты и времени,
отзывы с модерацией, личный кабинет и админ-панель с ролями.

## Технологии

| Что | Чем сделано |
|---|---|
| Платформа | .NET 10, ASP.NET Core MVC (Razor) |
| База данных | **SQLite** через Entity Framework Core (файл `App_Data/carservice.db`, создаётся автоматически) |
| Авторизация | Cookie-аутентификация, роли `Admin` / `Manager` / `User` |
| Пароли | `PasswordHasher` из ASP.NET Core Identity — PBKDF2 (HMAC-SHA512, 100 000 итераций, соль) |
| Защита | Antiforgery-токены на всех POST-формах, проверка ролей политиками `Staff` / `AdminOnly`, инвалидация сессии при смене роли/пароля/блокировке |
| Кеширование | `IMemoryCache` для услуг, слайдов, настроек, отзывов; OutputCache для JSON со слотами; статика с хешем версии и `Cache-Control: immutable` на год |
| Скорость | Сжатие Brotli/Gzip, без jQuery/Bootstrap — свой CSS (~20 КБ) и ~4 КБ JS |
| Дизайн | Тёмная тема (чёрный/серый + один акцентный цвет), адаптивная вёрстка, иконки — inline SVG |

## Запуск локально

```bash
cd car-service
```

```bash
dotnet run
```

Откройте http://localhost:5025. При первом запуске создаётся БД с демо-данными.
В Visual Studio — просто F5.

### Демо-аккаунты

| Роль | E-mail | Пароль |
|---|---|---|
| Администратор | admin@autoprofi.ru | Admin123! |
| Менеджер | manager@autoprofi.ru | Manager123! |
| Пользователь | user@autoprofi.ru | User123! |

Пароли задаются в `appsettings.json` → `Seed` и применяются только при создании новой БД.
**Перед показом на хостинге смените пароль администратора** (Админ-панель → Пользователи → «Ещё» → «Сменить пароль»).

Чтобы пересоздать базу с нуля — остановите сайт и удалите папку `car-service/App_Data`.

## Соответствие ТЗ

**Главная** (`/`): логотип и меню, слайдер-баннер (управляется в админке), блок «О сервисе», основные услуги,
выделенные отзывы со ссылкой на все, форма записи с выбором даты и свободного времени, кнопка «Позвонить»
(в шапке + плавающая на мобильных, ссылка `tel:`), контакты и карта (Яндекс.Карты), подвал со ссылками,
соцсетями, юр. информацией и командой разработчиков.

**Страницы меню:** `/About`, `/Services`, `/Booking`, `/Reviews`, `/Contacts` (+ форма обратной связи), `/Account`
(регистрация, вход, профиль, смена пароля, история записей с отменой, уведомления, мои отзывы).

**Роли:**
- *Администратор* — всё: услуги, баннер, сотрудники, расписание (часы, шаг, число постов, рабочие и нерабочие дни),
  заявки, модерация отзывов, пользователи и роли (смена роли, блокировка, сброс пароля, создание), контакты и настройки кнопки «Позвонить».
- *Менеджер* — сводка, обработка и подтверждение заявок (статус, перенос, заметка), просмотр отзывов без модерации, обратная связь.
- *Пользователь* — запись, личный кабинет, отзыв (только после выполненной записи — «после посещения сервиса»).

Клиент получает уведомление в кабинете при подтверждении/переносе/выполнении записи и при модерации отзыва.

## Структура

```
car-service/
├─ Program.cs                 — настройка: БД, авторизация, кеш, сжатие
├─ Data/                      — AppDbContext, DbSeeder (демо-данные)
├─ Models/                    — сущности БД и ViewModel-и
├─ Services/                  — BookingService (слоты), SiteCache, уведомления, иконки
├─ Controllers/               — публичные страницы и личный кабинет
├─ Areas/Admin/               — админ-панель (контроллеры + представления)
├─ Views/                     — Razor-разметка сайта
└─ wwwroot/                   — css/site.css, js/site.js, js/booking.js
```

## Публикация в интернет (бесплатно, открывается из РФ)

### Вариант 1 (рекомендуется): MonsterASP.NET

Бесплатный хостинг именно под ASP.NET: Windows + IIS, поддерживает .NET 8–11, **без банковской карты**,
без рекламы на сайте. Адрес будет вида `ваше-имя.runasp.net`. SQLite работает как обычный файл.

1. Зарегистрируйтесь на https://www.monsterasp.net/ и выберите бесплатный тариф (Free).
2. В панели управления создайте сайт (Website) — получите адрес `*.runasp.net`.
3. Опубликуйте проект одним из способов:
   - **Visual Studio (проще всего).** В панели MonsterASP найдите раздел деплоя (WebDeploy) и скачайте
     файл профиля публикации (`.publishSettings`). В VS: ПКМ по проекту → «Опубликовать» → «Импорт профиля» →
     выберите скачанный файл → «Опубликовать».
   - **Через FTP.** Соберите проект:
     ```bash
     dotnet publish car-service/car-service.csproj -c Release -o publish
     ```
     и загрузите **содержимое** папки `publish` в корень сайта через FileZilla (данные FTP — в панели MonsterASP).
4. Откройте адрес сайта. База `App_Data/carservice.db` создастся при первом запросе (первая загрузка — 5–10 секунд).
5. HTTPS на бесплатном тарифе включается вручную через тикет в поддержку — для показа можно и по http.
   После включения можно поставить `"UseHttpsRedirection": true` в `appsettings.json`.

Повторная публикация не затирает базу: папка `App_Data` в публикацию не входит.

### Вариант 2: любой хостинг с Docker (Render и др.)

В папке `car-service` лежит готовый `Dockerfile`. На Render: New → Web Service → подключить репозиторий GitHub →
Root Directory `car-service`, Runtime Docker, тариф Free. Минусы: бесплатный инстанс «засыпает» без запросов
(первое открытие ~30–60 сек), а файловая система не постоянная — база будет пересоздаваться с демо-данными при каждом перезапуске.
Доступность Render из РФ не гарантирована — проверьте заранее.

### Перед защитой

- Откройте сайт с телефона через мобильный интернет (без VPN) — убедитесь, что адрес открывается.
- Смените пароль администратора и впишите в «Контакты и настройки» → «Команда разработчиков» свои ФИО и группу.
